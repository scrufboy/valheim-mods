# Living World Formidable NPCs

Canonical human actor runtime for Living World **Formidable NPCs**: behavior,
parties, combat, recovery, migration, and raid-test implementation.

This package is an NPC consumer of the future standalone Formidable NPC Framework
and part of the Living World C.O.R.E. character/story system. It is neither the
framework nor the whole Core, and temporary Souls/RRR benchmark dependencies must
not be embedded as its permanent architecture. Package boundaries are defined in
[Living World Core project boundaries](../LivingWorldCORE/PROJECT-BOUNDARIES.md).

Current lab line: 0.3.x. Historical candidates belong under `archive/`, not beside the canonical source.

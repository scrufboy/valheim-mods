# Behemoth animation catalog: quick start

505 animation clips from 10 owned giant / golem / ogre-class Unity packs, categorized and measured, with a recommended clip set for the Draugr Behemoth.

- Humans: open `Behemoth-Animation-Catalog.xlsx` (start on the **Behemoth Set** tab), or the live Sheet: https://claude.ai/artifact/2iLRTi7ENAjRoCrP9RD6TQ
- Agents / bots: read `data/catalog.json` (array of clip objects) or `data/csv/*.csv`.

Key fields: `Clip`, `Pack`, `Family`, `Category`, `Type`, `Behemoth slot`, `Behemoth-ready`, `Seconds`, `Root motion`, `Speed (hip-heights/s)`, `Ground speed from foot contact (hip-h/s)`, `Body rise (hip-h)`, `Body drop (hip-h)`, `Fastest limb (hit candidate)`, `Fastest-limb time (s)`, `Loop (authored)`, `Notes`.

Units are hip-heights (the pack's standing hip height), so different-scale packs compare directly.
Nothing here has been viewed in game; see `HANDOFF.md` and `VERIFICATION.md` for what is and is not proven.

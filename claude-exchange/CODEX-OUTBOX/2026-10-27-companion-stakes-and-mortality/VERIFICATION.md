  companions need real cost/investment, counts must be bounded, and death must
  require finding a new person rather than resurrection.
- DESIGN-AUTHORITY: two active, six bonded, five-day next-lead eligibility,
  persistent world-only recruitment, permanent death, recoverable equipment, and
  memorial identity.
- SOURCE-INSPECTED: current lab uses explicit fresh-spawn commands and already
  distinguishes test markers; competitor audits documented respawn/revive systems
  that Living World now explicitly rejects.
- NOT IMPLEMENTED: no runtime spawn, roster, death, traversal, or persistence code
  changed in this documentation pass.
- SAFETY-GATED: permanent death cannot ship before traversal and authoritative
  death bookkeeping are live-proven.

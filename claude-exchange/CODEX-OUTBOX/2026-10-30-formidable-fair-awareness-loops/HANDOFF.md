# FormidableAI fair awareness and execution loops

Brian has clarified the fair-play boundary. FormidableAI should expose trained response opportunities,
not manufacture successful outcomes. The NPC still has to navigate, negotiate enemy pressure, react to
interruptions and complete the action through native Valheim mechanics.

Combat is the heaviest reasoning context and needs nested event/tactical/coordination/strategic loops,
all sharing one frame and arbitrator. Immediate attackers can interrupt a rescue or positioning plan,
but the higher purpose remains in memory for resume or deliberate abandonment.

The architecture and owner decisions now record fair knowledge, attempted-versus-accomplished action
lifecycle and the required feedback loop.

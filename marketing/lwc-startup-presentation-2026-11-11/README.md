Profile scope: `LWC Formidable Arena` only.

Title hierarchy:

1. `LIVING WORLD C.O.R.E.` using the approved cracked-stone/orange LWC wordmark.
2. `Valheim — Deep North 1.0`.

Integration uses Azumatt ChangeOfScenery 1.0.6 for the owned start-scene camera framework and exact supplied menu music, plus Azumatt Logo Changer 1.0.12 for profile-local title replacement. No global Valheim asset is edited.

The music file is copied byte-for-byte from Brian's supplied chat attachment. ChangeOfScenery owns playback and looping. The source is already mastered at approximately -14.9 LUFS / -1.2 dBTP, so no destructive audio processing was applied.

The title build script produces both framework-native target ratios with transparent backgrounds and conservative safe margins. Valheim was not launched as part of this installation; runtime and in-game visual confirmation remain pending explicit authorization.

# Living World C.O.R.E. Tooler

Maintained and packaged for Living World C.O.R.E. by **Brian / scrufboy**.

This package preserves the original ValheimTooler interface, colors, catalogs,
and feature set. It adds a fifth **Living World** toolbar section for companion
and combat-test commands. Invalid unfinished ObjectDB item entries continue to
be skipped without flooding `LogOutput.log`.

Default original interface key: **Delete**. Existing ValheimTooler key settings
are preserved when present.

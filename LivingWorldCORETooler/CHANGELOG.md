# Changelog

## 2.0.0

- Renamed and namespaced the package as Brian's unified Living World C.O.R.E. Tooler.
- Merges Living World NPC controls and the useful Valheim Tooler command surface into one opaque, tabbed panel.
- Adds player, item/prefab spawn, world, terrain, map, and admin tabs.
- Keeps specialized Living World waves and real native Valheim raids as clearly separate controls.
- Removes the old tooler's startup item-catalog crawl and permanent patch-heavy design that produced repeated errors.

## 1.0.1

- Adds one-click buttons for real native Valheim boss-army and creature raid events.
- Keeps controlled Living World waves separate from native raids so their cleanup behavior is explicit.

## 1.0.0

- Adds an Insert-key Living World Lab control panel with a generated, configurable BepInEx shortcut.
- Ignores the toggle while the player is typing in chat, console, Valheim text input, or the Tooler command field.
- Replaces the translucent gameplay overlay with an opaque dark window and solid information panels for reliable readability.
- Adds sections for lifecycle, community/casual behavior, combat, party recovery, specialized raids, destructive controls, and arbitrary future commands.
- Adds two-step confirmation for destructive actions.
- Preserves Human NPC Lab world/authority safeguards.
